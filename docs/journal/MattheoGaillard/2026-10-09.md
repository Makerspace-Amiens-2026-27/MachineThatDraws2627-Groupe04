# 2026-10-09 : création des journaux et prise en main de GitHub

**Séance :** planifiée · (séance étalée sur 2 jours)

## Fait

- Création de la structure des journaux : un dossier par étudiant, un fichier `index.md` et un fichier par séance au format `AAAA-MM-JJ.md`, avec le même template (Fait / Pourquoi / Reste à faire).
- Découverte de Git et GitHub : dépôt, clone, commit, push.
- Installation et configuration de Visual Studio Code pour éditer les fichiers Markdown.
- Problèmes rencontrés avec le site et avec VS Code, qui ont bloqué une partie de l'équipe.
- Travail repris sur un second jour pour que **tout le monde soit opérationnel**.

## Pourquoi

Les journaux servent à tracer les décisions et les essais de chacun, et le rapport final sera évalué sur sa capacité à être réutilisé par d'autres. Il fallait donc que chaque membre sache documenter proprement avant de lancer la conception. La séance s'est étalée sur deux jours à cause des blocages techniques : le projet avance mieux si personne n'est resté sur le côté.

## Reste à faire

- Terminer la mise en route des membres qui ne sont pas encore opérationnels.
- Valider que chacun peut commit et push son journal.
