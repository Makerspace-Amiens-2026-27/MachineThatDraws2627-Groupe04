# 2026-09-25 : étude de l'existant et choix du type de machine

**Séance :** planifiée · 

## Fait

- Recherche de machines à dessiner existantes pour s'en inspirer : AxiDraw (cité dans le sujet), projets open source de traceurs Arduino/GRBL, imprimantes 3D et traceurs CNC.
- Comparaison des architectures possibles : cartésienne (X/Y), CoreXY, polaire, bras SCARA, [autres].
- Choix de partir sur une **machine cartésienne**.

## Pourquoi

Une machine cartésienne déplace une tête de dessin sur des axes perpendiculaires (X, Y, et parfois Z) pour atteindre n'importe quel point d'une zone de travail rectangulaire. C'est le système de base de nombreuses imprimantes 3D et traceurs CNC. Les raisons du choix :

- simple à construire et à calibrer ;
- précision élevée, adaptée aux dessins techniques ou détaillés ;
- compatible avec le matériel du projet : moteurs pas à pas, servo pour le lever de stylo, Arduino + CNC Shield.
