# 2026-10-09 : étude de la machine cartésienne (séance 3)

**Séance :** planifiée · **Durée :** 3 h (9h–12h)

## Fait

- Recherche et compréhension du fonctionnement d'une machine cartésienne.
- Étude de la motorisation : un moteur pour l'axe X et un moteur pour l'axe Y.
- Amélioration du dépôt GitHub : journal de bord rendu plus professionnel.

## Pourquoi

Un système cartésien déplace l'outil selon deux axes perpendiculaires. Chaque axe a son propre moteur, souvent un moteur pas à pas, qui entraîne le chariot par une courroie crantée. Cela permet de positionner l'outil avec précision.
